
# AirSeparator — Codex Instructions

## Project
AirSeparator is an educational aviation separation simulator.
- Backend: C++20
- Frontend: React + TypeScript
- Version 1: Static simulated aircraft
- The C++ engine owns all distance calculations and warning decisions.
- AI explanations are educational and cannot change engine results.

## Development Rules
- The developer is learning and writes much of the code.
- Do not create, edit, or delete files unless explicitly requested.
- Explain proposed changes before implementing them.
- Work on one small task at a time.
- Prefer simple, readable, testable code.
- Explain unfamiliar C++ concepts in plain English.
- Do not install dependencies, commit, or push without permission.
- After changes, explain how to verify them.
